# LLM-generated spike trains and wavelet analysis

## О проекте

Репозиторий содержит код для вычислительного исследования временных
рядов спайковой активности, полученных из активаций большой языковой
модели (LLM), и их сравнения с экспериментальными данными. Часть этапов, 
относящихся к обработке графа, получения активных троек клеток и расчета
рядов ребер и троек во времени опущена, так как относится к другим репозиториям.

В `llm_generate_spikes.ipynb` языковая модель **Qwen2.5-1.5B**
обрабатывает текст из набора WikiText-2. Во время инференса из активаций
нейронов выбранного слоя извлекаются события, которые переводятся в
бинарную матрицу спайков (время × нейроны) с помощью пороговой обработки
активаций. Далее по полученным спайкам строится динамический граф.

Последующие скрипты и Jupyter notebooks анализируют временные ряды,
связанные с количеством рёбер и троек графа, а также сравнивают
синтетические данные LLM с экспериментальными данными. Для частотного
анализа используется непрерывное вейвлет-преобразование (CWT) с
вейвлетом Морле. Рассчитываются матрицы вейвлетной мощности, усреднённые
спектры и локальные спектральные наклоны. Ноутбуки визуализируют
распределения, спектры, спектрограммы и поведенчески размеченные участки
данных.

## Состав репозитория

### Основные файлы и модули


| Файл | Описание |
| :--- | :--- |
| `llm_generate_spikes.ipynb` | Основной ноутбук генерации синтетической спайковой активности с помощью Qwen2.5-1.5B. Загружает модель и WikiText-2, токенизирует текст, выполняет потоковый инференс чанками, извлекает активации нейронов слоя, применяет порог для получения матрицы спайков и сохраняет её. Затем восстанавливает по спайкам динамический граф и сохраняет его. |
| `wavelet_analysis.py` | Базовые функции вейвлетного анализа: подготовка и нормализация сигнала, вычисление матрицы мощности непрерывного вейвлет-преобразования с вейвлетом Морле и усреднение мощности по времени. |
| `graph_construction.py` | Функции построения динамического графа по спайковым событиям, включая поиск событий с временной задержкой и формирование связей в заданном временном окне. |
| `graph_io.py` | Функции подготовки графа к сохранению и загрузке: упаковка представления графа, получение неориентированного представления, формирование пути к файлу, сериализация и чтение сохранённых данных. |
| `freq_distribution.py` | Функции построения и оформления распределений, в том числе двойных панельных графиков, а также подгонки статистических распределений (например, отрицательного биномиального и степенного/дзета-распределения, логнормального распределения). |
| `spectrogram_visualization.py` | Функции визуализации исходных временных рядов и локальных вейвлетных спектров: создание макета рисунка, отображение сигналов и CWT-мощности, выделение всплесков и провалов, добавление скобок, цветовых шкал и обозначений панелей. |
| `spectral_slope_calc.py` | Расчёт спектральных наклонов по средней вейвлетной мощности. Содержит загрузку и подготовку спектров, интерполяцию на логарифмическую частотную сетку, оценку локального наклона, вычисление сводных метрик и построение сравнительного рисунка для рёбер и троек. |


### Jupyter notebooks для анализа и построения рисунков

| Ноутбук | Содержание и создаваемые графики |
| :--- | :--- |
| `draw_freq_distribution.ipynb` | Загружает временные ряды числа троек для экспериментальных данных и данных LLM. Строит сравнительные распределения частот/значений активности в двух панелях. Для экспериментальных данных включает подгонку кривой распределения, для синтетических данных — подгонку отрицательного биномиального распределения. Основная функция построения импортируется из `freq_distribution.py`. |
| `draw_number_of_edges_spectra.ipynb` | Сравнивает спектральные характеристики временного ряда числа рёбер для экспериментальных данных, LLM и пуассоновской нуль-модели. Вычисляет среднюю вейвлетную мощность, строит нормированный спектр и график локального спектрального наклона. Если файл нуль-модели отсутствует, генерирует независимые пуассоновские спайки, рассчитывает соответствующий ряд числа рёбер и сохраняет результат для повторного использования. |
| `draw_spectral_slopes.ipynb` | Рассчитывает метрики спектрального наклона для рядов числа рёбер и троек по нескольким экспериментальным записям и для синтетических данных LLM. Использует `spectral_slope_calc.py`. Строит двухпанельный сравнительный график локальных максимумов наклона и среднего наклона в заданной частотной полосе; результат сохраняется в PDF и PNG. |
| `draw_spectrogram.ipynb` | Загружает экспериментальный и синтетический временные ряды числа троек, вычисляет для каждого матрицу CWT-мощности и переводит её в децибелы. Строит сравнительный рисунок: исходные сигналы и соответствующие вейвлетные спектрограммы. На графиках отмечаются заданные временные интервалы всплесков и провалов. Функции визуализации находятся в `spectrogram_visualization.py`. |
| `draw_spectrum_data_different_windows.ipynb` | Сравнивает вейвлетные спектры числа рёбер и троек для экспериментальных данных и LLM при двух размерах временного окна построения графа (40 и 80 кадров). Строит отдельные панели для рёбер и троек; источник данных кодируется цветом, размер окна — типом линии. |
| `fig_triples_behavior.ipynb` | Сопоставляет поведенческие метки ручной разметки с временным рядом числа троек. Загружает разметку из CSV, вычисляет вейвлетную мощность всего ряда и строит спектральные кривые, усреднённые отдельно по кадрам каждой поведенческой категории. Категории с заданными исключёнными метками не отображаются. |
| `llm_generate_spikes.ipynb` | Ноутбук генерации данных, описанный выше в разделе основных файлов. Помимо извлечения спайков, содержит этап построения и сохранения динамического графа. |


## Выходные данные

В зависимости от настроек и наличия исходных файлов ноутбуки сохраняют
промежуточные данные и рисунки. Среди форматов, используемых в проекте:

-   `.npz` --- матрицы спайков, временные ряды и/или результаты
    вейвлетного анализа;
-   `.json` --- кэш рассчитанных метрик спектральных наклонов;
-   `.pdf` и `.png` --- итоговые графики.

Конкретные имена файлов и каталоги вывода задаются в ячейках настройки
соответствующих ноутбуков.

## Данные и настройка путей

Ноутбуки содержат переменную `work_dir` или `data_dir` с локальным путём
к рабочей директории. Перед запуском замените эти пути на расположение
данных и репозитория в вашей системе. Также проверьте пути к
экспериментальным данным, файлам разметки и ранее сохранённым
результатам CWT.

В репозитории присутствует код анализа, но исходные наборы данных и
результаты вычислений должны быть доступны отдельно, если они не
включены в поставку репозитория.

## Общая последовательность работы

1.  Запустить `llm_generate_spikes.ipynb`, чтобы получить синтетическую
    спайковую активность из активаций LLM и построить динамический граф.
2.  Подготовить или разместить экспериментальные и синтетические
    временные ряды в каталогах, указанных в ноутбуках.
3.  Запустить нужные ноутбуки `draw_*.ipynb` для построения
    распределений, спектров, спектрограмм и оценки спектральных
    наклонов.
4.  Проверить каталоги вывода, заданные в ноутбуках, чтобы получить
    итоговые рисунки в PDF/PNG.

Порядок может меняться в зависимости от того, какие исходные данные и
промежуточные результаты уже подготовлены.
